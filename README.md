# advpms.com.br

Site público do PMS Advogados Associados (OAB/RJ 130.903), publicado pelo GitHub Pages.

- `/reajuste/` — simulador de reajuste de planos de saúde "falso coletivo".
- `/` e páginas inexistentes redirecionam para `/reajuste/`.

Regras do repositório: apenas código. Nenhum documento, dado pessoal ou informação de cliente (LGPD e sigilo profissional).
